Background

Built for the Wavesbychin sound practice. You speak or type a dream, optionally answer a few refining questions, and receive a reading in five parts.

How it works

  • Five sections — dream analysis, interpretation, an I Ching / 梅花易數 cross-reference, a matched soundscape and art prompt, then a shareable insight.
  • Voice or text — dictation in English, 廣東話 and 普通話, with an eight-language interface.
  • Works without credentials — with no API key the server still serves a demo reading, clearly flagged, so the flow can be shown at any time.
