Background

A dashboard that pulls broker and bank exports into one place and writes a plain-English briefing each morning. No database — everything is flat JSON on disk.

How it works

  • Briefing over dashboard — rather than only charting balances, it writes a short daily note on what actually changed and what is worth thinking about, explicitly framed as information rather than advice.
  • Ingest pipeline — parsers for Trading 212 and Vanguard exports plus spending CSVs.
  • Scheduled — a morning briefing and a watchlist check run as scheduled jobs and notify over Telegram.
