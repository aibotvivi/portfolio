Background

A local web app where a "Director" agent proposes and runs work across the other projects in the workspace, one stage at a time, so each change is planned, built, tested and reviewed before it lands.

How it works

  • Four stages, one verdict — planner, coder, tester and reviewer each hand off a file, and the run ends in an explicit SHIP or FIX FIRST.
  • Opt in per project — projects start disabled; enabling one is what grants the agents write access to that folder.
  • Cancellable — a running cycle can be stopped from the UI.
